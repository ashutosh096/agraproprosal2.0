# District Integrated Environmental Programme

Interactive District Proposal Deck (16 curated slides) for environmental & urban resilience initiatives.

## Features
- Complete 16-slide presentation tailored for district administration briefings
- Comprehensive overview: Background, 6 core offerings, implementation timelines, and institutional governance
- Fully responsive HTML5 presentation with zero external runtime dependencies

## Deployment
This repository is configured for immediate deployment to **Vercel**, **GitHub Pages**, or any static web host. The main entry point is index.html.
